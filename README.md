# imnotbink — Tyler Schrimper portfolio

Personal portfolio + beat store. Static site: `index.html`, `style.css`, `script.js`.

- **Beats** live in `beats/` — add an mp3 there and register it in the `BEATS` list at the top of `script.js` (title, vibe, price).
- **Images** live in `img/`.
- Buy buttons open a pre-filled email to tylerschrimper@gmail.com.
- `awesome-design.md` — design resource list (from github.com/gztchan/awesome-design) for inspiration.

Deploy: push to GitHub and serve with GitHub Pages.
